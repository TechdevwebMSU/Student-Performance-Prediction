# 🎓 Student Performance Prediction

This project predicts student academic performance using machine learning models. It integrates SQL-based data exploration and preprocessing, with a full end-to-end ML pipeline in Python.

## 📊 Project Highlights

- Achieved **96% accuracy** in classifying student performance (Low, Medium, High) using a Random Forest model.
- Conducted experiments with both **classification and regression** models to determine the most effective approach.
- Improved data quality by **33%** through preprocessing: missing value handling, label encoding, and feature scaling.
- Leveraged **SQLite + SQL** for structured data analysis and ML-ready dataset creation using custom views.
- Visualized key features influencing academic success using **feature importance plots**.

## 🛠️ Technologies Used

- Python, Pandas, NumPy
- Scikit-learn, Matplotlib, Seaborn
- SQLite, SQL (via `sqlite3`)

## 📈 Sample Outputs

- **SQL query results** for EDA (average grades by gender, etc.)
- **Accuracy Score:** 96%
- **Feature Importance Plot:** Shows the top attributes affecting performance
